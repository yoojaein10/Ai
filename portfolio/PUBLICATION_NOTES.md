# 공개용 사본 안내

이 디렉터리는 원본 개발 폴더의 전체 프로젝트를 소스 중심으로 정리한 공개용 사본입니다.
원본 파일과 기존 Git 이력은 옮기지 않았습니다. 기존 저장소의 프로젝트는 유지했습니다.

- 비밀번호·API 키·직접 입력된 인증 값은 샘플 값으로 바꿨습니다.
- 연락처·주민등록번호 형태·내부 서버 IP·일부 사용자 경로를 샘플 값으로 바꿨습니다.
- 실제 설정은 제외하거나 `.example` 템플릿으로 바꿨습니다.
- 실제 업무자료·영상·이미지·엑셀·PDF·DB 파일·로그·실행 상태·백업·빌드 산출물은 제외했습니다.
- 실제 데이터 삽입용 SQL 시드는 제외했습니다.
- 프로젝트별 외부 코드 출처 문서는 유지했습니다. 외부 작성 코드를 본인 작성 코드로 주장하지 않습니다.

공개 사본은 완성도·운영 안정성·전체 테스트 통과를 보증하지 않습니다.
일부 프로젝트는 제외된 사내 시스템·설정·자료·아이콘에 의존하므로 그대로 실행되지 않을 수 있습니다.
실행하려면 README와 샘플 설정을 참고해 로컬 환경을 구성하고 필요한 자료를 합성 데이터로 대체해야 합니다.
원본의 문서·테스트에 기록된 성과는 과거 기록이며 이번 업로드에서 재측정한 결과가 아닙니다.
