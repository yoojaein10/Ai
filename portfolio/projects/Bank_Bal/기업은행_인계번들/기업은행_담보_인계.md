# 기업은행 담보 auto-fill — 인계 문서 (2026-08-25)

## 요약
기업은행(IBK) 담보의 **소스 추출 → 매핑**을 완성했습니다. 이 매핑이 만든 값을 받아서
**BANK24 화면에 자동입력**하는 부분을 만드시면 됩니다. (입력 부분은 신한/국민용 `ui/form.py`를
그대로 재사용 가능 — 라벨 기반이라 은행 무관.)

**검증 결과(01-2608-3-2683)**: **23칸 일치 / 1칸 불일치(용도지역=도메인 노이즈, 우리 값도 정확).**

## 1. 폼 / 소스 구조
- **BANK24 폼 클래스**: `TBNKKIB24DAMB` (KIB = 기업은행)
- **.gam 소스**: `land_list`(명세표) 기반 — **국민 토지 문서와 거의 동일**. `KB_*`(국민 전용) 테이블 없음.
- **적용 대상**: 실사완료(`apw_masterex.ConductDate` 있음 = .gam 존재) 문서만.
  실사 전 신규 의뢰(ConductDate 없음)는 .gam이 없어 채울 소스가 없음 → 자동 스킵.
  ※`ReportDate`는 최근건 다 비어 있어 지표 아님. **`ConductDate`가 지표.**

## 3. 검증 방법
화면에 기업은행 담보폼 열어둔 상태에서:
```
python tools/verify_fill_ibk.py 01-2608-3-2683
```
`✅일치/❌불일치/🖊우리채움(화면빈칸)/📄화면만` 으로 필드별 대조. 새 문서로 계속 검증 가능.

## 4. 자동입력 — **이미 만들어짐** (`tools/autofill_ibk.py`)
```
python tools/autofill_ibk.py <문서번호>          # 드라이런(계획만, 안전)
python tools/autofill_ibk.py <문서번호> --live   # 실제입력(빈칸만, 연습건 먼저!)
```
- `ui/form.py`(라벨로 칸 찾아 set_text + 되읽기검증, 메시지기반이라 마우스 안 뺏김) 재사용.
- **순번 정합 내장**: 화면 감정평가액↔우리 물건 금액매칭(없으면 일련번호)으로 채울 물건 선택. 불명확하면 실입력 보류.
- **일련번호는 앵커라 안 씀**(form.ANCHOR_LABELS), 순번 어긋남 방지.
- 안전: 기본 드라이런 · --live도 빈칸만 채움(--overwrite여야 덮음) · 되읽기 불일치시 정지 · 사람이 저장.
- 실측 2412: 순번 정합 표시 ✅, 14칸 일치, 콤보 6칸 수동, 라벨없는 3칸(법정동·소재지·심사자) 미발견.
- **남은 입력 과제(v2)**: ① 콤보/라디오 자동선택(물건종류·용도지역·부동산구분·공부지목·번지구분·평가사명 = 현재 수동)
  ② 라벨없는 칸(소재지·법정동·심사자) 위치기반 타겟팅.
