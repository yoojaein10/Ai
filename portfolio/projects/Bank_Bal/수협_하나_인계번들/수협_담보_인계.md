## 3. 자동입력 (`tools/autofill_ssb.py`) — ⭐ 승격(관리자) 필요
```
python tools/autofill_ssb.py 01-2608-3-2609          # 드라이런(계획만, 안전)
# 실입력은 관리자 승격으로(-Bank 생략 시 수협):
powershell -ExecutionPolicy Bypass -File tools\elevated_fill.ps1 01-2608-3-2609 -Live
```
- **왜 승격**: 이 세션=Medium, BANK24=High integrity → UIPI가 쓰기(EM_REPLACESEL) 차단.
  `elevated_fill.ps1`이 UAC로 High 자식프로세스를 띄워 우회(실측: 쓰기·되읽기 통과).
- **안전장치**: 기본 드라이런 · 빈칸만(--overwrite여야 덮음) · 되읽기검증 · 순번정합 · 사람이 저장.
- **미지원 가드**: 물건구분 부동산 아니면(선박·어업권) 실입력 보류. rollup·일단지 묶음머리도 보류.
- **--select 봉인**: 콤보 자동선택은 감사 P0-D(닫힌 드롭다운 ENTER→저장 커밋)로 봉인.
  콤보(물건구분코드·번지구분·용도지역)는 **사람이 선택**.

## 5. 미지원 / residual
- **선박(어선) 19.7% · 어업권 4%**: 물건필드 완전 다름(선명·톤수·면허번호). `app_ship`·`sea0000`
  테이블. detail.py에 app_ship 등록됨(필터 제외라 None), sea 패밀리 미등록. **별도 매핑 필요.**
- **일단지 다물건**: 소스로 블록/필지 구분 불가(2637 블록합 vs 1158 필지분리 — BIGO='일단지'
  동일한데 화면 반대). 감정평가액·면적 사람검토. doc필드는 맞음.
- **일반건물 집계형**(2660류): 건물상세 칸 + 층유닛 합산 미완.
- **인천 행정구역 개편**(중구→영종구·서구→검단구, 2026): 우리 소스=최신구/화면=옛구. 데이터
  currency 차이(매핑버그 아님).
