## 3. 자동입력 (`tools/autofill_hnb.py`) — ⭐ 승격(관리자) 필요
```
python tools/autofill_hnb.py 01-2609-3-2751          # 단일물건 드라이런
# 실입력은 관리자 승격으로(UAC) — -Bank hnb 필수(기본값은 수협):
powershell -ExecutionPolicy Bypass -File tools\elevated_fill.ps1 01-2609-3-2751 -Bank hnb -Live
  (또는 승격 cmd 에서 python tools\autofill_hnb.py 01-2609-3-2751 --live)
```
- **왜 승격**: Medium 세션 → High BANK24 폼 쓰기는 UIPI 차단. UAC 승격으로 우회.
  **실측: 2352 물건1 12칸 실입력 성공**(평가사·계좌·주소·번지·감정평가액·면적·건물명·건물용도·등기·준공).
- **다물건 순회(--all)**: 폼 안 좌/우 그리드로 행 이동(폼마다 다름, `_row_key` 감지). 각 행의
  **번지로 소스물건 매칭**해 채움. 순번 네비게이션 실측 확인(1→2→3).
- **안전장치**: 기본 드라이런 · 빈칸만 · 되읽기검증 · 번지/순번 정합 · 사람이 저장.
- **미지원 가드**: 물건종류 부동산(토지·건물) 아니면 실입력 보류. rollup 시 면적·금액 None.
