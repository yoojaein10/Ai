## 2. 검증 (화면에 우리 담보폼 열어둔 상태)
```
python tools/verify_fill_wrb.py 01-2608-3-2668
python tools/verify_grid_loop.py --bank wrb --max 20   # 자동 순회(승격)
```
**자동순회 20건: 진짜 매핑버그 0.** 불일치는 전부 노이즈(용도지역 정식/축약 혼용·호'외'표기·
상업용 물건종류·일단지 residual).

## 3. 자동입력 (`tools/autofill_wrb.py`) — ⭐ 승격(관리자) 필요
```
python tools/autofill_wrb.py 01-2608-3-2668          # 단일 드라이런
python tools/autofill_wrb.py 01-2608-3-2668 --all    # 전물건 순회 드라이런
# 실입력은 승격(UAC)으로. --all --live·--select 는 봉인(아래).
```
- **다물건 순회(--all)**: **오른쪽 그리드**가 물건 selector(실측: DOWN→순번 1→6, 감정평가액
  소스와 정확일치). 21물건도 전부 순회. 순번기반+감정평가액 교차검증.
- **안전장치**: 드라이런 기본·빈칸만·되읽기검증·순번정합·사람이 저장.
- **미지원 가드**: 부동산 아니면 보류. rollup 가드.
- **봉인**: `--all --live`(순회)·`--select`(콤보)는 감사 P0(틀린행·저장커밋)로 봉인 →
  `--i-understand-experimental` 로만.
