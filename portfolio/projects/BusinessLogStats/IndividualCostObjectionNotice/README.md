# 개별부담비용 이의신청 안내 자동 발송

## 검토 결과

구현 가능하다.

- 발송 채널: 기존 다우오피스 개인 알림 발송 API 재사용 가능
- 발송일: 매월 말일부터 역산한 마지막 영업일
- 영업일: 토요일, 일요일, 대한민국 공휴일·대체공휴일을 제외한 날
- 실행 방식: Windows 작업 스케줄러가 매일 1회 트리거하고, 프로그램이 당일이 해당 월의 마지막 영업일인지 검사
- 중복 방지: `발송연월 + 안내종류` 단위 발송 이력을 저장하고 이미 완료된 달은 재발송하지 않음

기존 참고 구현:

- `../VariableCost_NotiSend.jsp`: 월별 수신자 조회, 다우오피스 로그인 및 개인별 발송
- `../VariableCost_NotiTrigger.bat`: Windows 작업 스케줄러 트리거
- `../../ScheduleApp/backend/app/tasks/scheduler.py`: 예약 발송 및 발송완료 상태 처리
- `../../ScheduleApp/backend/app/services/daou_service.py`: 다우오피스 발송 서비스
- `../../D_INSA/INSA-salary-usb/backend/app/services/holiday_service.py`: 주말·공휴일 영업일 판정

## 발송 문구

```text
[개별부담비용 이의신청 안내]
해당 월의 개별부담비용에 이의가 있는 경우 익월 3일까지 이동희 국장에게 이의신청해 주시기 바랍니다.

이의신청 시 아래 사항을 기재해 주세요.
① 감정서번호
② 일자
③ 입력시간
④ 이의신청 내용

※ 기한 내 이의신청이 없는 경우 해당 비용에 동의한 것으로 처리되오니 업무에 참고하시기 바랍니다.
```

## 날짜 판정

1. 현재 월의 달력상 말일을 구한다.
2. 말일이 주말 또는 공휴일이면 하루씩 이전으로 이동한다.
3. 처음 만나는 영업일을 발송일로 정한다.
4. 오늘이 발송일이고 해당 월 발송 이력이 없을 때만 발송한다.

공휴일은 서버 DB에 연도별로 등록하는 방식을 우선 권장한다. 외부 공휴일 API를 사용할 경우 장애 시 누락되지 않도록 로컬 캐시와 실패 차단이 필요하다. 회사 자체 휴무일까지 제외하려면 동일 공휴일 표에 별도 등록한다.

## 구현 전 확정할 항목

- 수신 대상: 전 직원, 특정 부서 또는 특정 사용자 목록
- 발송 시각
- 공휴일 범위: 대한민국 법정·대체공휴일만 적용할지, 회사 휴무일도 포함할지
- 운영 전 테스트 수신자 계정

## 보안·운영 원칙

- 다우오피스 계정, DB 비밀번호, 트리거 인증값은 소스나 배치 파일에 직접 넣지 않고 서버 환경설정으로 주입한다.
- 발송 엔드포인트는 인증값 검증, 허용된 실행 방식, 요청 제한을 적용한다.
- 로그에는 비밀번호, 세션 쿠키, 인증값 및 불필요한 개인정보를 기록하지 않는다.
- 일부 수신자 발송 실패를 집계하고 안전하게 재시도할 수 있도록 결과를 저장한다.

## 채널 확인

기존 프로젝트의 이른바 `알림톡`은 카카오 알림톡이 아니라 다우오피스 메신저의 개인 알림 API이다. 요청한 채널이 이 다우오피스 개인 알림이라면 그대로 재사용할 수 있다. 실제 카카오 알림톡을 의미한다면 승인된 메시지 템플릿과 별도 발송 사업자 API 정보가 추가로 필요하다.
