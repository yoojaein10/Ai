## 핵심 발견 (v0.17 개선 대상 근거)

1. **동일 유형 질문의 라우팅 비일관** — "X 테이블 건수" 6문항 중 3개는 data,
   3개는 metadata로 갈림(1·4·6번). 경로가 흔들리면 답의 형태·정확도도 흔들린다.
   → v0.17 단일 호출 통합(route 필드) + 로컬 규칙 힌트의 근거.
2. **metadata 경로에서 허구 수치 확인** — 1번 "APW_Master 전체 건수" 질문에
   146만 행이라고 답했으나 실제는 73만 행. 카탈로그 요약(크기 상위 15)에 없는
   테이블인데 "알 수 없다" 대신 수치를 생성함. **기준선에서 확인된 실제 환각 1건.**
   → 건수 질문은 data 경로로 고정하거나, 자료에 없으면 거절 강제 필요.
3. **모호 질문 15번("접수 건수") 무단 추측** — 재질문 없이 용어집의
   등록이력(APW_RegHist)을 골라 COUNT SQL 생성. 업무 의미가 다를 수 있는데
   caveat도 비움. → v0.17 §6 재질문 트리거(검색 점수 낮음/후보 근접)의 근거.
4. **입력 토큰의 대부분이 테이블 목록** — data 경로는 테이블 1,500개 목록을
   매번 전송(질문당 ~10k 입력). → §1 로컬 검색으로 5~10개만 보내면 대폭 절감.
5. **data 경로의 테이블 선택 자체는 정확** (12/12) — 명시적 테이블명·용어집
   질문에서는 현 구조도 잘 맞음. 로컬 검색 전환 시 이 수준(Recall) 유지가 목표.
