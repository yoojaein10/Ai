AI DBA
      데이터 조회 · 객체/상태 질문 · 대화 맥락 기억

    
    
    
  

  

    
    
  


  

    

      

        질문 유형을 스스로 판단해 답합니다 — 데이터 조회는 SELECT를 만들어 드리고(실행 버튼을 눌러야 이 PC에서 조회),
        객체 질문(새 테이블·프로시저 등)과 상태·성능 상담은 수집된 자료로 바로 답합니다.
        프로시저 진단("SP_X가 느린 것 같아 파악해봐")은 소스 정적 분석 + 실행 통계 + 계획 회귀를 모아 진단합니다(이때 해당 소스가 AI로 전송됨).
        이전 대화를 기억하므로 후속 질문이 가능합니다.
      

    

    

      

        
        
      

      
질문·대화 맥락·객체 이름/생성일·마스킹된 SQL 구조는 Gemini로 전송, 데이터 값·조회 결과는 전송 안 됨. SELECT 외 명령 차단.

    

  


  

    

      용어집
