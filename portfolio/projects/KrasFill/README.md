# KrasFill — 일사편리 → 감정평가 워크북 자동 기입

일사편리(KRAS) 공개 조회 화면에서 토지이용계획·건축물대장 표제부를 가져와
HUG 감정평가 워크북의 `(토지이용)`, `(건축대장)` 탭에 자동 기입한다.

## 사용법 (편한 순서)

1. **GUI (exe)**: `dist\KrasFill.exe` 실행 → 폴더 지정 → ▶ 시작.
   파일 단위 진행률 바 + 실시간 로그, 중지 버튼 지원. **원본 워크북에 바로 기입**
   (기입 대상 셀만 갱신, 그 외 셀·사진·수식 보존. 대상 파일은 엑셀에서 닫아둘 것 —
   열려 있으면 해당 파일은 오류로 건너뛴다).
   exe 옆에 `settings.ini` 필요(DB 조회용, 없으면 주소 파싱 폴백으로 동작).
   재빌드: `python -m PyInstaller KrasFill.spec --noconfirm --clean`
2. **우클릭 → 보내기**: 탐색기에서 워크북(여러 개 선택 가능)을 우클릭 →
   보내기 → **KrasFill (일사편리 기입)**. 끝.
3. **드래그&드롭**: xlsx 파일들(또는 폴더째)을 `KrasFill.bat`에 끌어다 놓기.
   `KrasFill_DryRun.bat`은 기입 없이 대조만.
4. **명령줄**:

```
# 조회만 (엑셀 없이 데이터 확인)
python main.py --addr "경기 부천시 원미구 원미동148-21, 148-22"

# 워크북 대조 (기입 없이 기존 입력값과 차이만 보고)
python main.py "경로\워크북.xlsx" --dry-run

# 기입 — 파일/폴더 여러 개 가능 (기본: 원본에 바로 기입)
python main.py "경로\워크북.xlsx" "폴더경로" ...

# 복사본에 기입하고 싶으면 --out 지정 (원본 불변, *_KRAS.xlsx 생성)
python main.py "경로\워크북.xlsx" --out output
```

- **기본: 파일명의 감정서번호(예 01-2605-1-0265) → apworksdw APW_MasterEx 조회**로
  법정동코드(REG+EUB)·대표필지(SAN/BUN1/BUN2)·건물명을 확정한다 (읽기전용 SELECT, ? 바인딩).
- 전체 필지 목록은 **파일명/워크북 헤더 주소 > (정식) 탭 F열 > DB 대표필지** 순으로 확보.
  파일명이 '외 N필지'로 일부만 적었으면 나머지를 (정식) 탭에서 보충한다
  ('외' 표기 없는 파일은 잔여 목록 오기입 방지를 위해 보충하지 않음).
  DB 대표필지가 목록에 없으면 경고 후 맨 앞에 추가.
- 토지이용 근거 셀(국토계획/다른법령/시행령 C열)은 기입 후 돋움 9pt로 지정.
- 감정서번호가 없거나 DB 실패 시: 주소 파싱 폴백(파일명 → 워크북 헤더 → 일사편리 콤보 API로 코드 조회).
- DB 접속정보는 `settings.ini` [database] (없으면 Y_BankAuto\dist\settings.ini 차용).
- 기입은 실제 엑셀(COM)로 수행하므로 사진·도형·수식이 그대로 보존된다.
- 수식 셀(제한1~3, 목록, 비교 행)은 건드리지 않는다 → 워크북 자체 검증 수식이 그대로 동작.
- 실행 결과로 "기존 값과 다른 셀 N건" 리포트가 출력된다 (0건이면 완전 일치).

## 기입 범위

| 탭 | 채우는 것 | 안 채우는 것 |
|---|---|---|
| (토지이용) | 필지별 소재지/지번/지목/면적, 국토계획 지역지구, 다른법령 제한, 시행령 9조 사항, **개별공시지가(B열)** (최대 10필지 블록) | 제한1~3 수식(E/F/G열) — 양식 자체 수식으로 보고 안 건드림(누락 양식 대응은 보류) |
| (건축대장) | 대상건물 표제부: 대지위치·지번·면적들·건축물수·건폐율·용적률·총호수·용도·구조·부속건축물(동/㎡)·허가/착공/승인일·위반건축물·최고층 | 호별 전유부 표(22행~) — 일사편리에 없음(KAIS 출처), 임대사례 1~3 블록(불필요 확정) |

※ 개별공시지가는 일사편리 응답의 t05 표에서 최신년도 값을 취한다.
  요청에 bobn/bubn 파라미터가 없으면 서버가 공시지가 백엔드 조회를 생략하고
  '연결에 실패' 페이지를 반환하므로 landcode에서 잘라 함께 보낸다(2026-08-11 해결).
  그래도 값이 비어 오면(실제 지자체 장애) 해당 셀을 건드리지 않고 경고만 출력한다.

## 구조

- `addr.py` — 파일명/주소 문자열 파싱 (시도·시군구·읍면동·지번 목록)
- `kras_client.py` — KRAS HTTP 클라이언트 + HTML 파서 (법정동코드 콤보 API, baseInfo/bldTitle)
- `fill_excel.py` — Excel COM 기입 (복사본 생성, diff 수집)
- `main.py` — CLI

## 다동(多棟) 건물 처리

- 파일명의 동 번호(예 '제101동', '107동')로 해당 동의 표제부를 선택한다.
  총괄표제부는 제외하며, 여러 동인데 동 번호를 특정 못 하면 오기입 방지를 위해 건축대장을 기입하지 않고 경고한다.
- 동별 표제부는 대지면적이 0으로 오므로 총괄표제부(bldRecapTitle)에서 보강한다.
  목록에 총괄 행이 간헐적으로 빠지면 1회 재조회하고, 그래도 0이면 셀을 건드리지 않는다(0㎡ 덮어쓰기 방지).
- 명칭(G9)은 수작업 관례를 따른다: 동명칭이 '101동' 꼴 번호면 명칭 뒤에 붙이고
  ('태형팰리스 101동'), 고유명이면 동명칭만 쓴다('광백드림빌').
- 병합 없는 생(raw) 양식이면 수작업 관례대로 셀 병합을 만들어준다
  (토지이용 블록당 6개: 국토계획/다른법령/시행령 세로 + 좌측 라벨, 건축대장 고정 14개).
  이미 병합된 양식은 건드리지 않고, 좌상단 외 셀에 값이 있으면 값 보호를 위해 병합을 생략한다.

  (`KrasFill.spec`, onefile·windowed, dist\KrasFill.exe).

## 제약·주의

- 검증된 시도는 경기(kras.gg.go.kr)·서울(kras.seoul.go.kr)·인천(kras.incheon.go.kr).
  타 시도는 같은 구조로 추정(`kras_client.SIDO_INFO`), 첫 사용 시 --dry-run으로 확인 권장.
- 인천은 서버가 구식 암호군만 지원해 https 접속이 불가 → SSLError 시 http로 자동 폴백.
  응답 인코딩도 시도별로 달라(경기/서울 EUC-KR, 인천 UTF-8) utf-8 → euc-kr 순으로 자동 판별.
- 일부 대장(인천서 발견)은 표제부 주구조가 빈 값 → 층별현황 최빈 구조로 보강해 기입.
- 서울은 baseInfo를 POST로 받으면 500을 반환해 GET으로 조회한다(경기도 GET 허용).
- 서울 서버가 간헐적으로 건축물 목록이 빠진 페이지를 반환하는 경우가 있어 1회 재시도한다.
- 일사편리 데이터는 증명서 효력이 없음 — 최종 근거서류는 발급본으로 확인.
- 요청 간 0.7초 간격(서버 부담 방지). 사이트 개편 시 파서 수정 필요.
