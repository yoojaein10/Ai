# 국내주식 모의투자

삼성전자(005930)의 KRX 공개 시세와 15분봉을 읽어 가상 원화로만 매매합니다.
증권사 계좌, API 키, 실제 주문 API를 사용하지 않습니다.

## 실행

```powershell
cd D:\AI\Claude\StockPaperTrader
python -m pip install -r requirements.txt
python app.py
```

브라우저에서 <http://127.0.0.1:8766>을 엽니다. 자동 모의매매는 최초 실행부터
켜져 있으며, VWAP·EMA·RSI·볼린저밴드·EMA60 중 4개 이상과 필수 추세 조건이
충족될 때만 매수합니다. ATR 손절·목표수익·추적손절을 적용합니다.

모의체결에는 매수·매도 수수료 각 0.015%, 매도세 0.20%, 체결 미끄러짐
0.05%를 반영합니다. 시세 제공처의 비공식 공개 인터페이스는 변경될 수 있습니다.
