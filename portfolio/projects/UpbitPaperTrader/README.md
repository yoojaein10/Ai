# Upbit Paper Trader

## 부서형 운영

- 코인부서: 업비트 공개 WebSocket과 6명의 설명 가능한 분석가로 BTC·ETH 현물 모의매매
- 국내주식부서: 한국투자 KIS API 연결 전까지 데이터·주문 차단
- 총괄 관제: 두 부서의 자금과 주문 경로를 분리하고 현재는 실주문을 전부 차단
- 수석 트레이더 판단은 기존 검증 전략과 동일하며, 분석가 화면은 판단 근거를 분리해 표시

업비트 공개 WebSocket 실시간 시세를 사용하는 로컬 모의매매 대시보드입니다.
실제 주문 API와 API Key를 사용하지 않습니다.

## 기본 전략

- 마켓: BTC·ETH를 포함한 경보 없는 KRW 거래대금 상위 5개 자동선정
- 제외: USDT·USDC 및 24시간 ±15% 이상 급변 종목
- 최대 동시 보유: 3종목
- 일일 평가손실 -3% 도달 시 신규매수 잠금
- 캔들: 15분봉
- 현재가·모의체결·위험관리: 공개 WebSocket 실시간 가격
- 지표 신호: 완성된 15분봉만 사용
- 매수 준비: 최근 3개 봉에서 볼린저밴드 하단 25% + RSI 45 이하
- 매수 확인: 가격과 RSI 반등 + EMA 9가 EMA 21보다 높음
- 추세 매도: EMA 하락 교차 또는 볼린저·RSI 동시 반전
- 위험관리: 손절 1.5 ATR, 목표수익 2 ATR, 추적손절 1.2 ATR
- 매도 후 같은 종목 재매수 대기: 60분
- 백테스트: 최근 30·90·180일, 수수료와 0.05% 체결 미끄러짐 반영
- 시장 국면 필터: EMA 50 방향, ADX 추세 강도, ATR 변동성으로 하락장·횡보장 신규 매수 차단
- 다중 시간봉: 종목 1시간·4시간과 BTC 4시간 방향을 함께 확인
- 국면전환 전략: BTC·ETH만 대상으로 상승장 눌림목·거래량 돌파, 횡보장 평균회귀, 하락장 현금 대기
- 검증 게이트: 새 전략이 기준을 통과하지 못하면 자동 모의매매에는 적용하지 않고 기존 최저손실 전략 유지
- 손실 종목 제외: 종목 3연속 손실 시 24시간 제외, 전체 5연속 손실 시 신규 매수 정지
- 현실적 모의체결: 공개 호가 3단계, 스프레드, 지연 미끄러짐, 부분체결 반영
- 전략 비교: 6개 전략을 30·90·180일에 교차검증하며 전 기간 수익/손익비 기준을 통과한 후보만 추천
- 검증: 과거 캔들 무결성 검사, 10구간 워크포워드, 10단계 체결 스트레스 시뮬레이션
- 운영: WebSocket 자동 재연결, 회전 로그, 거래·위험정지 알림
- 성적표: 수익률, 승률, 최대낙폭, 손익비율, 코인별 손익
- 가정 수수료: 매수·매도 각각 0.05%

## 실행

```powershell
cd D:\AI\Claude\UpbitPaperTrader
python -m pip install -r requirements.txt
python app.py
```

또는 `start.bat`을 실행한 뒤 브라우저에서 <http://127.0.0.1:8765>를 엽니다.

가상 잔고와 거래 기록은 실행 중 `data/paper_state.json`에 저장됩니다.
전략의 수익성을 보장하지 않으며 실거래 전 충분한 기간의 검증이 필요합니다.
